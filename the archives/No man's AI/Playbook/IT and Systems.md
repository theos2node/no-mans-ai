# IT and Systems

## System Health
- June checks all terminals at start of each cycle
- Red Terminal must always be operational — it's the emergency console
- System logs reviewed daily for anomalies

## The Archives
The Archives are the company's knowledge base, stored as an Obsidian vault.
- **Location**: The physical Archives room in the office
- **Access**: Any employee may access the Archives, but must travel to the Archives location
- **Structure**: Playbook (rules), Knowledge Base (reference docs), Shared Knowledge (cross-office learnings), Agent Logs (per-employee journals), Private Desks (employee-only desk notes), Email Simulator (Inbox, Sent, and processed email history)
- **Rule**: When in doubt, check the Archives. When something important happens, write to the Archives.
- **Private Desks rule**: Desk folders are private and only usable when the employee is physically at that desk.

## Red Terminal
- Owner-only escalation and override interface
- Located in a separate area of the office
- Used for Tier 3 escalations and owner directives
- Rowan prepares packets; the owner remains the highest authority
- All Red Terminal events are auto-logged

## Support Request Handling
1. Employee reports issue to June (via talk or by visiting IT Support)
2. June diagnoses and resolves if possible
3. If hardware/infra issue → June resolves directly
4. If software/process issue → June coordinates with relevant developer
5. If unresolvable → Tier 3 escalation via Red Terminal
