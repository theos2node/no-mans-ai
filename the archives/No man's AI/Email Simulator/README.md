# Email Simulator

Drop new inbox emails into `Inbox/` as plain markdown files.

Use this format:

```md
# Any title you want
From: Sender Name <sender@example.com>
To: Recipient Name <recipient@example.com>
Subject: Email subject

Email body goes here.
```

Notes:
- The desk PC list only shows subject, sender/recipient name, and time until an email is opened.
- Anything sent from the desk PC is written into `Sent/`.
- Processed inbox items are moved into `Processed Inbox/`.
- If you want a starting point, copy one of the files from `Templates/`.
